# S01 — Fundação da Aplicação

## Objetivo
Instalar e configurar Laravel 13, Inertia.js e Vue 3 sobre o ambiente Docker.

## Escopo
- criar projeto Laravel;
- instalar Inertia.js, Vue 3 e Vite;
- conectar PostgreSQL, Redis e Mailpit;
- configurar Pint e testes;
- criar layout-base e página inicial autenticável futuramente;
- definir convenções de código e estrutura inicial dos domínios.

## Critérios de aceite
- aplicação abre pelo Nginx;
- Vite funciona em desenvolvimento e produção;
- conexão com PostgreSQL e Redis está validada;
- migrations e testes executam nos containers;
- envio de e-mail de teste aparece no Mailpit;
- README contém comandos oficiais.

## Fora do escopo
Autenticação completa, cadastros e regras clínicas.
